# SQL Query Practice: Database Testing Foundations

Bu repository, bir Test Mühendisi olarak veritabanı doğrulama (**Database Testing**) ve veri manipülasyonu konularındaki yetkinliklerimi geliştirmek için hazırladığım SQL çalışmalarını içermektedir.

### Proje Yapısı ve SQL Konuları

Proje, temelden ileri seviyeye doğru şu klasör yapısı ile organize edilmiştir:

* **`basics/`**: Veri seçimi, filtreleme ve sıralama işlemleri (`SELECT`, `WHERE`, `BETWEEN`, `LIKE`, `ORDER BY`).
* **`aggregation/`**: Veri setleri üzerinde matematiksel hesaplamalar ve gruplandırma (`COUNT`, `SUM`, `GROUP BY`, `HAVING`).
* **`joins/`**: Birden fazla tabloyu ilişkilendirerek veri çekme teknikleri (`INNER`, `OUTER JOINS`).
* **`constraints/`**: Tablo oluşturma aşamasındaki kısıtlamalar ve veri bütünlüğü kuralları.
* **`subqueries/`**: Karmaşık veri sorguları için iç içe geçmiş sorgu mantığı.



### QA Perspektifi
Yazılım test süreçlerinde; veri tutarlılığını doğrulamak, backend testlerini gerçekleştirmek ve ihtiyaç duyulan test verilerini veritabanından çekmek amacıyla bu SQL yetkinliklerini kullanmaktayım.
